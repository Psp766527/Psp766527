# 💫 About Me:
I am a Senior Software Engineer and Backend Developer with 5+ years of experience specializing in Java, Spring Boot, Microservices Architecture, and Cloud-Native Engineering. I design and build scalable distributed systems using modern technologies like Java 17, Spring Boot 3.5, Spring Cloud, Kubernetes, Terraform, AWS/Azure, and Kafka.<br><br>I have successfully led major monolithic-to-microservices migrations, built enterprise-grade CI/CD pipelines, and engineered resilient cloud deployments for global clients across banking, insurance, automotive, and enterprise platforms.
